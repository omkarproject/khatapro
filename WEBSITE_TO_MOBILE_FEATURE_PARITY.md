# WEBSITE TO MOBILE FEATURE PARITY MATRIX

| Feature Area | Website Implementation | Native Android (`mobile-app/`) Implementation | Parity Status Plan |
| :--- | :--- | :--- | :--- |
| **Auth & Security** | Email/Phone/Username login, 10-min 3-fail lockout, 6-digit OTP signup/forgot, 2FA TOTP/Email, Active Devices, Single & All-Device logout | Native Auth screens calling `/api/auth/*`, `SecureStore` session, `/api/auth/devices`, Biometric unlock (`expo-local-authentication`) | 100% Parity + Biometric |
| **Dashboard** | 4 KPI cards (`KHATA`, `EXPENSES`, `NET AMOUNT`, `ONLINE COLLECTIONS`), Support strip, Top Pending, Expense Donut, Low Stock, Savings, Quick Add | Native Dashboard with identical KPI formulas, pull-to-refresh, `OfflineSyncNotch`, Quick Add bottom sheet, native charts | 100% Parity |
| **Digital KhataBook** | Customers + Groups, Udhar/Jama keypad, bills/PDF attachments, voice notes, split bills, edit audit trail, soft-delete/restore, Exclude toggle, PDF/WhatsApp statements | Native ledger chat UI, custom numeric keypad sheet, `expo-camera` / `expo-document-picker`, `expo-print` PDF statements, Android WhatsApp intent | 100% Parity |
| **P2P Merchant Ledger** | Auto-linked merchant badge, mirrored transactions, live edit/delete alerts, safe un-verify on delete | Calls `/api/users/lookup`, `/api/users/p2p-link`, `/api/users/p2p-mutate` + Supabase Realtime alerts & Android local notifications | 100% Parity |
| **GST Invoicing & Billing** | Sales/Purchase/Quotation, item catalog, GST/discount/charges, templates, stock deduction, PDF/print, status history | Native multi-step Invoice Builder, local catalog lookup offline, `expo-print` HTML→PDF templates matching web | 100% Parity |
| **Payments** | Direct UPI QR, Cashfree PG, Razorpay, UPI Gateway, `/api/pay/confirm` server verification | Native `upi://` intent launcher, Cashfree/Razorpay checkout + mandatory server verification via `/api/cashfree/verify`, `/api/razorpay/verify`, `/api/pay/confirm` | 100% Parity |
| **Customer CRM** | Profiles, credit limit, rating, bank/UPI accounts, Drive Vault folders/files, digital business card | Native CRM list + detail tabs, image/PDF previewer, shareable business card image/PDF | 100% Parity |
| **Expenses, Inventory, Savings, Reminders, Documents, Notes & Tasks** | Dedicated pages with CRUD, filters, budgets, stock alerts, deposits, vault lock | Native screens backed by SQLite + Sync Queue so all CRUD works offline and syncs reliably | 100% Parity |
| **Cloud Storage & Backup** | Google Drive ON → Drive only; OFF → `khatapro-media` Supabase Storage; JSON/ZIP export/import; Telegram backup | Uses `/api/backup/google-drive/upload-file` & `/api/db/sync` (`offloadSyncMediaToStorage`), local `expo-file-system` backup export/share | 100% Parity |
| **Admin Control Center** | Branding, Broadcasts, Maintenance, SMTP, Drive config, User CRM, Support Tickets, Factory Reset | Role-gated Admin screens (`role === 'admin' | 'super_admin'`) with explicit confirmation dialogs calling `/api/admin/*` and `/api/system/config` | 100% Parity |
